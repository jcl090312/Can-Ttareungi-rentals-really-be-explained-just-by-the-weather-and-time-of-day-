# 따르릉연구소: 따릉이 대여량은 정말 날씨와 시간대만으로 설명되는가?
## 팀원
- 20320 이서빈 / 20613 배준철
## 질문
"따릉이 대여량은 정말 날씨와 시간대만으로 설명되는가?"
## 왜 이 주제인가 (팀이 씁니다)
두명 모두 자전거를 대여해서 자주 이동하는 편이라서 궁금했다. 
- 20320 이서빈 : 내가 보통 자전거를 대여하여 사용할 때 날씨가 더워 빠르게 이동하고 싶거나, 비가 와서 비를 맞기 싫을 때 자전거를 사용해서 다른 사람들도 그런지 궁금했다
- 20613 배준철 : 자전거를 대여하여서 학원을 가거나 친구들과의 약속을 갈 때 사용하는 편인데, 진짜 필요할 때 공공 대여 자전거가 없어서 시간대가 중요한가 라는 생각이 들었다.
## 데이터
- 출처: 서울 열린데이터광장
- 기간·행 수·열 수: 720행 · 8열
- 사용한 열: 날짜와 시간, 해당 시간대의 따릉이 대여량, 기온, 강수량, 풍속, 시간대, 요일, 주말 여부
- 개인 단위 정보 없음 확인: 예
